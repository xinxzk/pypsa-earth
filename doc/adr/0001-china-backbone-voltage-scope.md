# China Backbone Voltage Scope

Accepted. The main China planning cases represent the backbone transmission network as AC and DC assets at 220 kV and above, with 110 kV excluded from the main case and reserved for sensitivity or finer provincial-network studies. The simplified AC network uses a 500 kV equivalent layer because PyPSA-Earth clustering requires a single-voltage representation, and 500 kV is a more representative national backbone approximation than 220 kV while avoiding an overly UHV-specific 750/1000 kV interpretation.
